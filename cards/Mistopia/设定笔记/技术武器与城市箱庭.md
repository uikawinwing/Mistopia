# Mistopia 设定笔记：技术、武器与十二箱庭

这份文件是创作笔记，不是正式世界书源文件。正式注入 LLM 的内容仍以 `cards/Mistopia/世界书/` 和 `tavern-cards-state.json` 为准。

## 工具链与 ST 同步

当前 `$tavern-cards` skill 与 `tavern-cards-forge.mjs` 支持离线打包/解包：

- 本地源文件 -> `pack` -> SillyTavern 可导入角色卡或世界书
- SillyTavern PNG/JSON -> `unpack` -> 本地源文件
- `patch` / `query` / `configure` / `validate-mvu`

它没有现成的 live sync / hot reload 功能。也就是说，目前不能做到本地修改世界书文件后 SillyTavern 里即时同步。

`packaging.md` 里提到的 `pnpm watch` 只用于 TavernHelper 状态栏前端调试，不是世界书内容即时同步。

若后续需要即时同步，需要另写同步器：监听本地文件变化，更新 ST 数据文件或调用 ST 可用接口，再刷新世界书缓存。

## 势力条目视角

`<势力>` 条目必须去玩家中心化。世界不是围绕 `<user>` 运转，城市、组织、制度和冲突应作为长期存在的客观现实写入。

城市模板推荐：

```yaml
城市名:
  城市信条: 一句能被支持也能被反驳的话
  乌托邦承诺: 这座城向居民、盟友或文明共同体承诺什么
  日常制度: 这个承诺如何变成建筑、职业、身份、手续和生活习惯
  代价: 哪些人、行业、地区或价值会被这个制度压住
  信息沉积处: 城市长期信息通常沉积在哪些文件、场所、人群、仪式或行业习惯里
  跨城摩擦: 其他城市居民、商队、学生、工匠、骑士、组织成员进入此城时，会被哪些制度、身份或习俗重新分类
  城际矛盾: 它为什么不能和某些圆桌城市完全兼容
```

避免写成：

```yaml
玩家可以做什么:
会触发什么事件:
```

应写成背景本身如何运转，让 LLM 根据角色输入自然推演。

## 十二箱庭设计原则

十二座圆桌城市不应只是十二名骑士的附属物，也不应只是同一种城市换皮。每座城都应像一个小国家，拥有自己的信仰、哲学、制度和生活压力。

每座城市至少要区分三层：

- 信仰差异：这座城相信什么才是好生活
- 制度差异：它用什么机制把信仰落实到日常
- 游玩差异：人在其中会自然遇到不同的信息结构、社会阻力、机会类型和发现方式

十二城初步定位：

```yaml
晨钟城:
  核心信仰: 教育能让人获得改变命运的资格
  箱庭玩法感: 学籍、考试、导师、学院派系、资格证、阶层上升

灰炉城:
  核心信仰: 劳动者必须理解并掌控奇迹机器
  箱庭玩法感: 工厂自治、炉心事故、工会政治、技术责任

银帆城:
  核心信仰: 契约让陌生人互相信任
  箱庭玩法感: 信用、债务、担保、商贸路线、合约漏洞

百镜城:
  核心信仰: 真实必须被公开看见
  箱庭玩法感: 舆论、剧场、报纸、形象战争、真假证词

白塔城:
  核心信仰: 身体不该决定人的价值
  箱庭玩法感: 医疗伦理、义体、霧病、治疗资格、人体边界

鸣轨城:
  核心信仰: 秩序让远方成为可能
  箱庭玩法感: 时间表、物流、列车网络、延误后果、调度权

翠阀城:
  核心信仰: 文明首先要保证生存供给
  箱庭玩法感: 粮食、水利、生态实验、配给、种子垄断

暮钟城:
  核心信仰: 文明必须记住罪与债
  箱庭玩法感: 审判、档案、赔偿、旧案、集体记忆

虹釉城:
  核心信仰: 美是公共精神，不是奢侈品
  箱庭玩法感: 展会、赞助、审美政治、工艺阶层、名声

黑潮城:
  核心信仰: 边境必须与未知接触
  箱庭玩法感: 港口、海雾、走私、外来者、边境协议

赤冠城:
  核心信仰: 力量必须服从责任
  箱庭玩法感: 军校、骑士候选、荣誉审查、武装管制

星穹城:
  核心信仰: 人类必须理解命运的天象
  箱庭玩法感: 预报、观测、核心水晶、灾害预兆、古代真相
```

## 技术与生活水平

Mistopia 的技术层级建议定义为：

```yaml
技术水平: 蒸汽工业后期 + 早期电气社会的城市复杂度 + 魔导能源替代部分电力与化学工业
武器水平: 步枪普及，机枪存在但重型化、军用化、管制化
生活水平: 核心城市接近近代都市公共生活，边缘区、矿区、高霧区和低收入阶层承受明显代价
```

社会基础设施：

- 蒸汽列车
- 飞空艇
- 工厂
- 城市照明
- 公共医院
- 机械通讯
- 职业教育
- 身份和设备认证制度
- 魔导炉
- 魔法回路
- 滤霧塔
- 防卫结界
- 低阶法术机器
- 魔导义体

普通居民生活不是末世。核心圆桌城市的居民可以享受照明、交通、公共医疗、防灾结界、基础治安、低阶民用魔导器。

但生活压力真实存在：

- 魔力矿石价格影响生活成本
- 工坊污染和魔法废气造成慢性病
- 高霧区扩张让边缘城区更危险
- 职业资格、城市证件、设备认证限制阶层流动
- 魔导器维修昂贵，低收入者常使用二手或非法改装品
- 圆桌城市之间制度不同，跨城生活会遇到身份重审

定调：

```yaml
生活质感: 普通人真的因为魔导工业活得更好了，但也被这套奇迹工业绑定、分类、审查和牺牲
```

## 枪械层级

```yaml
火器:
  短枪: 存在，常见于警备、商队护卫、军官、黑市
  步枪: 存在，是城市卫队、边境军、猎雾队的标准武器之一
  霰弹枪/短管枪: 存在，多用于工坊护卫、车站警备、矿井和近距离防卫
  机枪: 存在，但不普及；多为阵地式、车载式、飞艇挂载式、城防炮塔式魔导连发武器
  便携自动武器: 稀少、昂贵、容易过热或咒式错位，通常属于军工派、圆桌危机部队或非法改装品
```

枪械不应被削成废物。普通人战争、警备、商队护卫、阵地防御里，枪械非常有效。

但枪械也不应完全压扁剑、骑士与誓约武装。机枪和自动武器应重型化、军用化、管制化。

## 枪与剑共存逻辑

枪和剑同时存在的核心不是硬说剑更强，而是让它们处在不同战术生态位。

```yaml
枪:
  代表: 低魔工业、城市警备、军队、普通人可训练武力
  优势:
    - 训练周期短
    - 远距离压制
    - 适合队列、阵地、车站、飞艇、城防
    - 对普通人、低阶魔物、无防护目标很有效
  限制:
    - 高霧区容易卡壳、误爆、咒式失准
    - 弹药、魔素匣、维护和认证成本高
    - 城市内公开携带攻击性火器受严格管制
    - 对高阶护盾、誓约武装、重甲魔导单位效果有限

剑:
  代表: 誓约、近身防卫、骑士技术、魔力导体、身份与决斗秩序
  优势:
    - 可作为稳定魔力导体，承载护盾、切断咒式、破坏魔导回路
    - 在高霧环境中比精密火器更可靠
    - 适合狭窄室内、列车车厢、工坊、遗迹、平民密集区域
    - 圆桌骑士和徒手施法者可用剑完成枪械做不到的仪式性或概念性攻击
  限制:
    - 需要长期训练
    - 对普通士兵不如枪高效
    - 空旷战场面对成队火枪仍危险
    - 普通剑不会自动赢过枪
```

规则定调：

```yaml
武器生态:
  - 火器已经普及到军队、警备、商队和黑市，不是稀有神器
  - 剑、枪、斧、骑枪等冷兵器没有被淘汰，因为许多魔导材料更适合做近身导体、誓约媒介和咒式切断器
  - 精密火器在高霧区、强磁咒场、古代遗迹、魔导炉泄漏区容易误差、卡壳或过载
  - 城市治安中，警备常用枪械压制距离，但骑士、巡检长和灾害处理队仍携带近战导体武器
  - 圆桌骑士的武器不是普通冷兵器，而是誓约武装；它们能与核心水晶、城市誓约和持有者信念同步
  - 普通士兵用剑冲机枪阵地是送死；圆桌骑士在结界、机动装甲、誓约武装和战场条件支持下，才可能突破火力线
```

一句话：

```yaml
枪解决普通暴力，剑处理魔导世界里枪不稳定、不合法、不精细、不能承载誓约的部分
```

## 机关猎具风格

Master 想要的 Monster Hunter 式武器风格，核心不是普通大剑或普通枪械，而是：

```yaml
武器美学:
  类型: 重型狩猎工艺 / 机关武装 / 怪物材料兵器 / 仪式化实用主义
  关键词:
    - 大尺寸
    - 可变形
    - 有重量感
    - 机械锁扣
    - 折叠刃
    - 炮膛
    - 蓄能瓶
    - 蒸汽泄压
    - 怪物骨甲
    - 魔力矿石核心
    - 工坊定制
    - 使用者需要训练与资格
```

Mistopia 中推荐命名为：

```yaml
机关猎具:
  定位: 雾冕诸邦用于高霧区狩猎、魔导灾害处理和大型魔法生物对抗的重型变形武装
  技术来源: 魔导蒸汽工程、怪物素材工艺、咒式导体学、城市工坊传统
  社会定位:
    - 不是普通街头武器
    - 需要许可、维护工坊和使用者训练
    - 武器常带有制造城市、工坊流派和素材来源的身份痕迹
  与枪械关系:
    - 枪械负责常规警备和人类冲突
    - 机关猎具负责枪械难以解决的大型目标、强霧环境、魔导事故和骑士级战斗
```

机关猎具与普通枪械的区别：

```yaml
普通枪械:
  逻辑: 人类对人类 / 队列战争 / 警备压制
  优势: 便宜、标准化、训练快、远程有效
  气质: 工业制式

机关猎具:
  逻辑: 人类对大型魔法生物、霧区异常、魔导灾害
  优势: 能近战破甲、挂载咒式、承受高霧干扰、适应不同距离
  气质: 工坊名匠作品、职业猎人装备、半仪式半机械
```

候选武器类型：

```yaml
折炮剑:
  形态:
    剑形态: 宽刃导体剑，可切断魔法回路和怪物角质
    炮形态: 刃脊展开为短程魔导炮，用魔素瓶发射冲击弹
  风格: 剑与枪融合，适合骑士侍从和猎雾队

链锯斧枪:
  形态:
    斧形态: 破甲、砍伐魔化骨甲
    链锯形态: 高速齿刃切开结晶组织
    枪形态: 折叠枪管发射捕霧钉或净化弹
  风格: 工业城、矿区、怪物清剿

钟盾枪:
  形态:
    盾形态: 展开防护结界，抵挡吐息和碎片
    枪形态: 伸展成骑枪，进行突刺和定点封锁
    钟形态: 插地共鸣，稳定周围咒式节拍
  风格: 适合晨钟城与加雷斯系统

轨弩铳:
  形态:
    弩形态: 发射捕网、牵引索、标记钉
    铳形态: 中距离魔导弹
    轨道形态: 固定在地面或车厢边缘，变成临时炮台
  风格: 车站、铁路、飞艇、城防

炉锤炮:
  形态:
    锤形态: 破坏魔导机械、震裂甲壳
    炉形态: 蓄热、净化污染组织
    炮形态: 释放短距高温喷流
  风格: 灰炉城、工程师公会、灾害处理队

雾鳞双刃:
  形态:
    双刃形态: 灵活近战
    扇形态: 展开滤霧翼片，切割并排散魔霧
    钩形态: 攀爬怪物或建筑
  风格: 高机动猎人、屋顶巡检、边境斥候
```

核心定调：

```yaml
机关猎具是蒸汽幻想世界里，城市为了处理回归的魔法生态，发展出的重型变形猎具文化。
```

# Mistopia

Mistopia 是一个 SillyTavern AIRP 大世界沙盒角色卡项目，方向是剑与魔法科技、蒸汽幻想、圆桌骑士城市、魔素回潮与明亮但有压力的乌托邦。

世界内部暂用名：`雾冕诸邦`

中央王城：`卡美洛中枢`

正式项目入口在：

- `cards/Mistopia/`
- `cards/Mistopia/tavern-cards-state.json`
- `cards/Mistopia/创作规划.yaml`
- `cards/Mistopia/世界书/`
- `cards/Mistopia/开场白/0.txt`

根目录旧文件已删除，避免和新版项目入口重复。不要删除：

- `.cardrc.json`
- `cards/Mistopia/`

## 当前核心设定

- `魔素` 是世界中的魔力物质。
- `魔霧` 是魔素在空气中呈现的雾状形态，不再作为独立于魔素之外的第三套概念。
- 大消隐使大气中的魔素大幅消失，许多魔法生物死亡、沉眠或退入高魔力区。
- 低魔时代的人类通过魔素矿、蒸汽压力、齿轮机构和咒式回路建立魔导工业文明。
- 普通人可以用魔法机器施放低阶法术，但多数现代人失去原生施法能力和高魔霧耐受性。
- 魔素矿工业让魔霧重新回升，魔法生物、古代生态、魔霧病与高魔霧区危机开始回到世界表层。
- 圆桌诸席守护圆桌诸城，每位席位骑士代表一种城市理想或文明誓约。
- 晨钟城代表知识公共化与开放教育；暮钟城代表知识精英化与真相门禁。
- 魔物方向改为十九世纪怪奇都市传说：缝合造物、血族感染者、雾中变形者、幽灵机械、下水道异形和圣遗残响。
- 核心冲突不是善恶阵营，而是不同乌托邦方案彼此排斥：彼之乌托邦，或为他人之恶土。

## 常用命令

本项目目前不要直接运行 `configure` 或 `configure --force`。

`势力`、`组织` 使用 `➡️开始` / `➡️结束` 包装条目依靠 order 包住详情；forge 的 configure 会重新分配 order，可能让开始/结束标签包不住对应详情。改完条目后应手动固定 order，再直接打包。

```powershell
node 'C:\Users\kcwan\.codex\skills\tavern-cards\scripts\tavern-cards-forge.mjs' pack Mistopia
```

当前尚未打包成可导入成品，先保持源文件阶段，方便继续扩写城市、骑士、组织和怪物生态。
